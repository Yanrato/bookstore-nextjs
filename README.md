# Catálogo de Livros em Next.js

Projeto desenvolvido utilizando Next.js e TypeScript com foco em prática de desenvolvimento front-end moderno.

## Tecnologias utilizadas

* Next.js
* TypeScript
* React
* CSS

## Funcionalidades atuais

* Exibição de livros
* Estruturação de páginas
* Componentização
* Navegação entre seções

## Próximas melhorias

* Integração com banco de dados
* Sistema de pesquisa
* Favoritos
* Responsividade aprimorada

## Objetivo

Praticar desenvolvimento de aplicações web modernas utilizando React e Next.js.
